
## Border Size Customizer

BetterDiscord 外掛 / BetterDiscord Plugin

`BorderSizeCustomizer.plugin.js` 可以在 Discord 中自由調整：  
`BorderSizeCustomizer.plugin.js` lets you customize the following in Discord:

- 整體視窗的邊界寬度與圓角
  - Overall window border width and corner radius
- 伺服器列表的邊界寬度與圓角
  - Server list border width and corner radius
- 頻道側邊欄的邊界寬度與圓角
  - Channel sidebar border width and corner radius
- 訊息區域的邊界寬度與圓角
  - Message area border width and corner radius
- 所有區域共用的邊界顏色
  - A shared border color for all areas

### 安裝方式 / Installation

1. 安裝並啟用 BetterDiscord。  
   Install and enable BetterDiscord.
2. 開啟 BetterDiscord 的「外掛資料夾」。  
   Open the BetterDiscord plugin folder.
3. 將 `BorderSizeCustomizer.plugin.js` 放入該資料夾。  
   Copy `BorderSizeCustomizer.plugin.js` into the folder.
4. 在 Discord 的「設定 → 外掛」中啟用 **Border Size Customizer**。  
   Enable **Border Size Customizer** under Discord **Settings → Plugins**.
5. 開啟外掛設定，即可即時調整各區域的寬度與圓角。  
   Open the plugin settings to adjust each area's border width and corner radius in real time.
